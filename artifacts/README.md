# artifacts/

Where Sage saves **deliverables** — the things you'd forward to someone else: HTML reports,
slide decks, diagrams, one-pagers, study sheets.

**Naming:** `artifacts/<topic>/<date>-<slug>.html` (e.g.
`artifacts/launch-plan/2026-06-04-rollout.html`).

When does Sage render an artifact instead of just answering in chat? When the answer
benefits from layout, diagrams, comparing 3+ options, interactivity, or a scannable digest —
anything with structure you'd want to keep or share. Otherwise, plain chat/markdown.
