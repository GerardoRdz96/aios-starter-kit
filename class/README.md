# class/ — Teaching materials

Everything you need to teach a class on AI Operating Systems, built around this kit. All
bilingual (English / Español — toggle top-right in the HTML files).

| File | Audience | What it is |
|------|----------|-----------|
| [`explainer.html`](explainer.html) | Students (project it) | The visual explainer / slide deck: what an AIOS is, the anatomy, the knowledge wiki, skills vs agents vs routines, how it grows. Scroll top-to-bottom as you teach. |
| [`exercises.html`](exercises.html) | Students (hands-on) | Seven progressive exercises, from setup to building their first skill. Checkable steps that save progress locally. |
| [`facilitator-guide.md`](facilitator-guide.md) | You (the teacher) | Run-of-show with timings, the 5-minute live-demo script, anticipated questions, and credits to name. |
| [`meet-your-aios.mp4`](meet-your-aios.mp4) | Everyone | A 30-second motion-graphics showcase to open or close the class (1920×1080). Made with HeyGen HyperFrames. |
| [`images/`](images/) | — | The illustrations used in the explainer; reuse them in your own slides. |

**Quick start for teaching:** open `facilitator-guide.md`, then open `explainer.html` in a
browser and present. That's the class.
