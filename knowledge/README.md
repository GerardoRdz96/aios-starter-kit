# knowledge/

The **raw source drop zone** — layer 1 of your wiki. Drop things here exactly as they
arrive: meeting transcripts, PDFs, articles, exported notes, YouTube transcripts, screenshots.

**Rules**
- Sources here are **immutable**. Sage reads them but never rewrites them.
- Keep originals in their native format (`.pdf`, `.docx`, `.vtt`). Derived text goes to `.md`.
- Interpreted facts **graduate** into the wiki at `references/` — that's where Sage writes.
  The raw source stays here as the citation.

**Source registry** — when you add a meaningful source, note it below so provenance is
traceable.
